Proyecto de Práctica Git - M2AE7
Este proyecto fue realizado para practicar el flujo de trabajo con Git y GitHub, incluyendo el manejo de ramas y Pull Requests.

 Funcionalidades implementadas

Estructura básica:

Creación de los archivos iniciales del proyecto.
Barra de Navegación: Implementación de un encabezado funcional en la rama `feature/navbar`.
Pie de Página: Implementación de un footer mediante un flujo de Pull Request.

Ramas utilizadas
1. `main`: Rama principal del proyecto.
2. `feature/navbar`: Rama para el desarrollo del encabezado.
3. `feature/footer`: Rama utilizada para practicar la integración mediante Pull Request.
